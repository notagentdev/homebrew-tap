# notagent Homebrew tap

Install notagent on an Apple Silicon Mac:

```sh
brew install --cask notagentdev/tap/notagent
```

Update an existing installation:

```sh
brew upgrade notagent
```

Source and releases: [notagentdev/notagent](https://github.com/notagentdev/notagent).

Documentation: [notagent.dev](https://notagent.dev/).
